# Week 04 — AWS Cloud

**Focus:** Brief overview for this week.
How to securely enable cross-account access to Amazon S3 without relying on long-term credentials. It highlights using AWS IAM roles and Security Token Service for temporary, auditable access between AWS accounts. The solution emphasizes least privilege, trust policies, and CloudTrail monitoring to maintain a secure and scalable multi-account setup.
