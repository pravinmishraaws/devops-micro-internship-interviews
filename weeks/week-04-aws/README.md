# Week 04 — AWS Cloud

**Focus:** Brief overview for this week.
How to design a secure and scalable VPC architecture on AWS that allows public web servers to serve internet traffic while keeping backend databases private and isolated. It tests knowledge of subnets, routing tables, Internet Gateway (IGW), NAT Gateway, and how to apply security groups and network ACLs for layered protection.
